# Learn SecByte CTF Labs: Git Recon, Nmap, Gitleaks, DarkHole & RPyC Root

A focused collection of Learn SecByte CTF and hands-on cybersecurity labs covering GitGhost discovery, Git security, Apache reconnaissance, Nmap, port discovery, Gitleaks, DarkHole, RPyC, and root-focused scenarios.

This repository provides a searchable learning index for cybersecurity students, CTF players, ethical hacking learners, penetration testers, SOC analysts, and security learners working in authorized environments.

## Introduction

The supplied labs cover multiple practical cybersecurity themes, including:

- GitGhost and Git repository discovery
- Git security and path discovery
- Apache reconnaissance
- Nmap and port discovery
- Gitleaks and repository secrets
- DarkHole
- Root-focused CTF scenarios
- RPyC and root-related scenarios

Use all linked resources only against authorized lab environments.

## Categories

### Git Security

The Git-focused labs cover GitGhost reconnaissance and discovery, GitShadow path discovery, Apache-related Git inspection, and Gitleaks-related secret discovery.

### Network Reconnaissance

**Nmap Clues Unlocked** explicitly identifies Nmap, while **Port Whisper** identifies port discovery as its central theme.

### Web Security

**Git Peek Apache** connects Git-related discovery with Apache, while **DarkHole Deploy Lab** is grouped under the DarkHole theme identified by its URL.

### Gitleaks

**Gitleaks to Rootkit** explicitly identifies Gitleaks and a rootkit/root-focused scenario in its URL. The repository therefore categorizes it under Git security and privilege escalation without adding unsupported technical claims.

### RPyC

Both **RPyC Root Vikings Expedition** and **RPyC Root Route** explicitly identify RPyC and root-focused objectives in their URLs.

## Learning Path

A practical sequence for exploring this collection is:

1. Start with **Nmap Clues Unlocked** and **Port Whisper** for reconnaissance-oriented labs.
2. Explore **GitGhost Recon** and **GitGhost Discovery**.
3. Continue with **Git Shadow Path** and **Git Peek Apache**.
4. Study **Gitleaks to Rootkit** for the secrets/root-focused scenario.
5. Explore **DarkHole Deploy Lab**.
6. Continue with **Raid to Root Flags** and **Keys to the North**.
7. Finish with the two **RPyC Root** labs.

Difficulty levels are not specified by the supplied URLs, so this repository does not assign difficulty ratings.

## How to Use the Labs

1. Select a lab from the direct index.
2. Open the corresponding Learn SecByte resource.
3. Follow the lab's documented setup and instructions.
4. Work exclusively against the authorized CTF/lab environment.
5. Document the security concepts and findings you encounter.
6. Review defensive implications and possible mitigations where appropriate.
7. Never test systems without explicit authorization.
